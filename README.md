## 🌟 About the Project / О проекте

This project is part of the **Anti-AI Shield** ecosystem. It is a standalone HTML application designed to help students prepare for the Russian Unified State Exam (EGE) in German Language (2026 format). 

Проект входит в экосистему **Anti-AI Shield**. Это автономное веб-приложение, помогающее школьникам подготовиться к Единому государственному экзамену (ЕГЭ) по немецкому языку в формате 2026 года.

### ✅ Key Features / Ключевые возможности

*   **🌐 Bilingual Interface (RU/EN):** Switch between Russian and English with one click in the top right corner. All tasks, explanations, and menus are translated.
    *   *Двуязычный интерфейс:* Переключение RU/EN одной кнопкой. Задания, пояснения и меню переведены.
*   **⏱ Smart Exam Timer:** Built-in countdown timer mimicking the real exam conditions (190 minutes for written part). Visual warnings when time runs out.
    *   *Умный таймер:* Имитация условий реального экзамена (190 минут). Визуальные предупреждения об истечении времени.
*   **🎧 Audio Support:** Supports official audio files (`audio-de.mp3`, `audio-de-oral.mp3`). If files are missing, backup educational voiceovers via browser Speech Synthesis are used automatically.
    *   *Поддержка аудио:* Работает с официальными файлами. При отсутствии файлов включается резервная озвучка браузера.
*   **📝 Full Coverage:** 
    *   Listening (Tasks 1–9)
    *   Reading (Tasks 10–18)
    *   Grammar & Vocabulary (Tasks 19–36)
    *   Writing (Tasks 37–38) with automatic word count checker.
    *   Speaking (Tasks 1–4) with models and timers.
*   **📅 Study Plan:** A structured 25-day preparation course for Grade 11 students.
*   **✅ Checklist:** Interactive progress tracker that resets on page reload (privacy-focused).
*   **🔒 Privacy First:** No servers, no cookies, no tracking. Runs 100% locally in your browser.

## 🚀 How to Use / Как использовать

1.  **Download:** Clone this repository or download the ZIP file.
    ```bash
    git clone https://github.com/YOUR_USERNAME/anti-ai-qwen-academy-german-ege-2026.git
    ```
2.  **Prepare Audio (Optional):** For the best experience, place the official exam audio files next to `index.html`:
    *   `audio-de.mp3` (Written part)
    *   `audio-de-oral.mp3` (Speaking part, Task 3)
3.  **Run:** Simply open `index.html` in any modern web browser (Chrome, Edge, Firefox, Safari).
